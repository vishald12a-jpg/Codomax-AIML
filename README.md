# Codomax AI/ML - Module 2

## Python Mini Project - Student Grade Calculator

### Project Description

The Student Grade Calculator is a beginner-friendly Python command-line application.

It accepts marks for five subjects and calculates the student's total marks, percentage, grade, and pass/fail result.

### Subjects

* Mathematics
* Python
* DBMS
* Operating Systems
* AI/ML

### Features

* Student name input
* Subject mark input
* Mark validation
* Total marks calculation
* Percentage calculation
* Grade calculation
* Pass/Fail checking
* Multiple student calculations
* Invalid input handling

### Python Concepts Used

* Variables
* Input and output
* Functions
* Conditional statements
* While loops
* Lists
* Exception handling
* Built-in functions

### How to Run

Open the terminal inside the project folder and run:

```bash
python student_grade_calculator.py
```
