
# Student Performance Prediction System

A beginner-friendly machine learning project that estimates a student's final mathematics grade using Python, Pandas, Scikit-learn, and Streamlit.

## Project Overview

This project uses a Random Forest regression model to estimate a student's final mathematics grade based on selected study-related information and earlier grades.

The application provides an interactive interface for entering student information, generating an estimate, and viewing a chart.

This is an educational project. Predictions are estimates, not guaranteed academic outcomes.

## Features

- Load and explore a student performance dataset
- Train a Random Forest regression model
- Evaluate the model using MAE, RMSE, and R-squared
- Estimate a student's final mathematics grade
- Display previous grades and the estimated grade in a chart
- Provide an interactive Streamlit interface

## Dataset

The project uses the Student Performance dataset from the UCI Machine Learning Repository.

Dataset page:
https://archive.ics.uci.edu/dataset/320/student+performance

Download and extract the dataset, then place `student-mat.csv` in the project folder.

### Input Features

- `studytime`: Weekly study-time category
- `failures`: Number of past class failures
- `absences`: Number of school absences
- `G1`: First-period grade
- `G2`: Second-period grade

### Target

- `G3`: Final mathematics grade

The dataset's grades range from 0 to 20.

## Installation and Setup

### 1. Clone the repository

```bash
git clone YOUR_REPOSITORY_URL
cd Module-6-Student-Performance-Prediction
```

Replace `YOUR_REPOSITORY_URL` with the actual GitHub repository URL. If you choose a different repository folder name, use that name in the `cd` command.

### 2. Create a virtual environment

```bash
python -m venv venv
```

### 3. Activate the environment on Windows

```bash
venv\Scripts\activate
```

### 4. Install the dependencies

```bash
pip install -r requirements.txt
```

### 5. Train the machine learning model

```bash
python train_model.py
```

This script loads the dataset, trains the model, prints the evaluation metrics, and creates `model.pkl`.

### 6. Start the web application

```bash
streamlit run app.py
```

Open the local URL shown in the terminal, usually:

http://localhost:8501

## Machine Learning Workflow

1. Load the dataset.
2. Select the input features and target variable.
3. Split the data into training and testing sets.
4. Train the Random Forest regression model.
5. Predict grades for the test data.
6. Evaluate model performance.
7. Save the trained model.
8. Load the model in the Streamlit application.
9. Enter new input values and generate an estimate.

## Evaluation Metrics

### Mean Absolute Error (MAE)

Measures the average absolute difference between actual and predicted grades. Lower values generally indicate smaller errors.

### Root Mean Squared Error (RMSE)

Measures prediction error while penalizing larger errors more strongly. Lower values generally indicate smaller errors.

### R-squared (R²)

Measures model fit relative to a baseline. A value closer to 1 generally indicates a better fit; negative values are possible.

Record the values printed by your own training run. Do not assume that the model will achieve a particular score.

## Limitations

The model is trained on a particular dataset and a limited set of features. Its predictions may be inaccurate for other students, schools, or populations.

Earlier grades are included as inputs, so this model is not intended to predict performance before any academic results are available.

The prediction should not be used for high-stakes decisions about students.
